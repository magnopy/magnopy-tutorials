Tutorials for magnopy
=====================

In this web-page you will find tutorials for |magnopy|_.

The "master" tutorial is accessible via the link below. We recommend to take it
if you would like to learn how to use magnopy. It will be regularly updated to keep up
with the updated of magnopy. 


.. toctree::
    :maxdepth: 2

    master-tutorial/index


Moreover, we collect below tutorials for magnopy that were given in the schools. Those
tutorials are aimed at the fixed version of magnopy and we are not planning to update
them regularly. School-specific tutorials all originated from the default one at some 
point of its history and were fine-tuned for the need of each school. If the school
introduced some new tutorials, then those are added to the default one as well.

.. warning::
    School-specific tutorials might be targeted at the outdated version of |magnopy|_. 
    We recommend to take :ref:`master-tutorial` if you are learning how to use magnopy.
